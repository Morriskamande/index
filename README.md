Set up instructions
Save the Code: Copy the complete HTML code provided previously and save it to your local machine as an .html file (for example, index.html).
Open in a Browser: Double-click the saved file or open it directly in any modern web browser (such as Chrome, Firefox, Edge, or Safari). No external server setup or installation is required since it utilizes CDNs for Tailwind CSS, Lucide Icons, and Chart.js.
Log In:
On the login screen, you will see the Reserved System Accounts card at the bottom containing the test credentials.
You can use the Quick Login Credentials buttons (Citizen Preset or Admin Preset) to automatically fill the fields, or type them in manually.
Once you sign in successfully, the reserved credentials card will automatically hide itself to keep the interface clean, but will reappear when you log out.
